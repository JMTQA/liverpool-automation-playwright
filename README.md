# 🛒 Liverpool UI Automation Framework

[![Automated UI Tests](https://github.com/TU_USUARIO/TU_REPOSITORIO/actions/workflows/test.yml/badge.svg)](https://github.com/TU_USUARIO/TU_REPOSITORIO/actions/workflows/test.yml)

Este repositorio contiene una solución de automatización end-to-end (E2E) desarrollada en **Java** con **Playwright** y **TestNG** para la plataforma e-commerce de Liverpool.

---

## 🚀 Requisitos Previos

Asegúrate de tener instalado lo siguiente en tu máquina local:

* **Java JDK 17** o superior.
* **Apache Maven 3.8+**.
* **Git**.

---
